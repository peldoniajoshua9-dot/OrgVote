Student Gmail & One-Time Password

Confirm each student's Gmail with the student, click Verify, then use Get OTP when they forget their password. The OTP can be emailed only to a verified Gmail.

Candidate Information

Party lists

Import from Excel or CSV

Use an Excel (.xlsx) or CSV file with the columns Party, Position, Name. Rows with an empty Name are skipped. New party lists are created automatically, and names already on the ballot are not added twice.

Add candidates

Pick the party list, then type only the names. Leave a position empty to skip it. Each party list can have 1 candidate per position and 2 Representatives for each grade level (Grades 7 to 12).

Voting Timer

Times use this computer's clock and time zone. Votes outside the window are rejected by the database.

Reset Ballot

This permanently deletes all votes and abstains so every student can vote again. Students, candidates and the whitelist are kept. It cannot be undone.

Admins

You are the Main Admin (supervisor). Only you can add or remove admins. When another admin asks to print the official results, you get a notice at the top of the page and can approve or deny it. Each admin has their own Admin ID.
